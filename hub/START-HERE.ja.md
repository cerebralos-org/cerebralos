# ハブを自分の環境に作る（日本語・最短ルート）

CerebraLOS Hub は、**あなた自身の Cloudflare アカウント**の上に作る、ダッシュボードとタスク共有の仕組みです。
スマホでも見られるダッシュボードと、「いま何をしているか」を AI たちと共有するボード（ToDo・ワークスペース分類つき）が手に入ります。
データはすべてあなたのアカウントの中だけにあり、作者や他の人には共有されません。

コマンドを自分で調べて打つ必要はありません。**AI（Claude Code）に質問されながら、一緒に組み上げます。**

## 用意するもの

- Cloudflare のアカウント（無料プランで始められます。[dash.cloudflare.com](https://dash.cloudflare.com) で作成）
- Node.js 20 以上
- Claude Code
- ターミナルの基本操作（コマンドは AI が用意します。実行の許可を求められたら内容を読んで答えるだけで大丈夫です）
- ふだん使うメールアドレス（ログインの許可に使います）

## 手順

1. このリポジトリをクローンして、フォルダに入ります。

   ```bash
   git clone https://github.com/cerebralos-org/cerebralos.git
   cd cerebralos
   ```

2. Claude Code を起動して、こう話しかけます。

   > ハブをセットアップして

   `setup-hub` というスキル（導入プレイブック）が働いて、AI が順番に質問と確認をしながら進めます。

## 進み方

| 段階 | 中身 | あなたがやること |
|---|---|---|
| 0 | 質問（呼ばれたい名前、メール、使いたい機能） | 答える |
| 1 | 環境の確認 | `wrangler login`（ブラウザで許可） |
| 2〜3 | 入れ物の作成と設定 | 内容を確認して「OK」 |
| 4 | **Cloudflare Access（ログインの鍵）** | ブラウザで画面を操作（AI が手順を案内） |
| 5〜6 | 秘密の値の登録、公開 | 確認して「OK」 |
| 7 | この Mac とつないで、最初のタスクを共有 | 動作を確かめる |
| 8 | スマホ通知・Slack・ChatGPT 連携など | 必要になったら追加 |

**まずは 0〜7 の「最小構成」を作ります。** 通知や外部連携は、慣れてから足せます。

## 大事な約束事

- パスワードや API トークンなどの**秘密の値を、AI とのチャットに貼らないでください。** AI は、値が画面に出ない手順で進めます。
- Cloudflare の画面操作（Access の設定）は、あなた自身が行います。
- 途中で止まっても、`hub/.setup-progress.md` に進み具合が残るので、次回は続きから再開できます。
- 動かなくなったら、その症状を AI に伝えてください。スキルに、よくある原因と直し方の表が入っています（`.claude/skills/setup-hub/SKILL.md` の Troubleshooting）。
